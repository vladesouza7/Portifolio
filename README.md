# Portfólio Vlademir Souza – Versão Moderna

Portfólio minimalista com:

- **Tema claro / escuro** (toggle + preferência do sistema + localStorage)
- **Internacionalização** completa: `pt-BR`, `en`, `es`
- Design limpo, tipografia Inter, responsivo
- Animações suaves de progresso e scroll
- Menu lateral moderno (colapsável no mobile)

## Estrutura

```
artifacts/
├── index.html
├── README.md
└── static/
    ├── css/style.css
    ├── js/
    │   ├── i18n.js
    │   └── main.js
    └── img/          ← coloque aqui as imagens originais
```

## Imagens necessárias

Coloque na pasta `static/img/`:

- `perfil.png` (avatar sidebar)
- `FOTO_PERFIL.png` (seção Sobre)
- `Blog_Post.png`
- `microblog.png`

Caso as imagens não existam, o site usa fallbacks automáticos (UI Avatars + Placehold.co).

## Como usar

Abra o `index.html` em qualquer navegador moderno ou sirva com um servidor estático.

Os dados pessoais, links, experiências, habilidades e percentuais foram **mantidos exatamente como no original**.
